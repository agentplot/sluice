# Tasks

Each group is one session's work for an implementer who reads this
change (proposal, design, specs) and its own group. The groups land in
order, as one landing. Work in this change's place on its branch, cut
from main. The code waits for the user's read of record 0083 (1.3). Run
suites through sluice (`sluice exec main -- cargo test ...`); a quick
`cargo check`, `cargo clippy` or one unit test may run directly. No test
reaches a credential or the host's own sluice state: set
`XDG_STATE_HOME` to the test's scratch directory, as the tests do now,
and give every sluice a test starts `support::isolated`. Tests use
temporary folders and repositories only. Commit by pathspec (`git add
<paths>; git commit -m "<subject>" -- <paths>`), Conventional Commits,
scoped to the part of the tree, citing clauses by number and rules by
id. The trailer's change is a `fix(core)` commit, so the release CI makes
from the landing is a new patch version. Every group ends with its check
task passing.
