# Tasks

Each group is one session's work for an implementer who reads this
change (proposal, design, specs) and its own group. The groups land in
order, as one landing. Work in the worktree
`github-is-asked-only-when-something-moved` on its branch. Run suites
through sluice (`sluice exec main -- cargo test ...`); a quick `cargo
check` or one unit test may run directly. No test reaches GitHub or a
credential: every forge test runs against the fake API in
`crates/sluice/tests/support/http.rs` or the file forge in
`crates/sluice/src/profiles/github/fake.rs`, with `XDG_STATE_HOME` set
to the test's scratch directory. Commit by pathspec (`git add <paths>;
git commit -m "<subject>" -- <paths>`), Conventional Commits, scoped to
the part of the tree, citing clauses by number and rules by id. Every
group ends with its check task passing.
