# Tasks

Work in this change's place on its branch, cut from
`bolt/a-sandboxs-refusal-blames-no-one`, which is its base. A quick
`cargo clippy` or one test by name of a fast target runs directly. A
test of the `tools` feature that starts no sandbox runs through
`sluice exec bolt/a-sandboxs-refusal-blames-no-one -- …`, as CLAUDE.md's
Running checks has it. macOS refuses a sandbox inside another (design,
"What macOS gives", 6), so a test that starts one has `sandbox` in its
name, which keeps it in the `cli:sandbox` task alone, and runs directly,
outside any. A unit test of the `sluice` crate never has `sandbox` in its
name, since `cli:test` skips those. No test reaches the host's own
sluice state: set `XDG_STATE_HOME` to the test's scratch directory.
Commit by pathspec, Conventional Commits, scoped to the part of the
tree, citing clauses by number, records 0072 and 0084 and rules by id.
Record 0072's amendment of 2026-11-11 and rule core.35's details are
already written on this branch.
