Each group is one session's work for an implementer who reads this
change (proposal, design, specs) and its own group. Read design.md's
"What is built on this branch" first: most of the core is built, under
the former words, and the groups say what is left. Work in the worktree
`outcomes-are-delivered` on its branch. Run suites through sluice
(`sluice exec main -- cargo test ...`); a quick `cargo check` or one
unit test may run directly. Commit by pathspec (`git add <paths>; git
commit -m "<subject>" -- <paths>`), Conventional Commits, scoped to the
part of the tree, citing clauses by number and rules by id. Every group
ends with its tests passing.
