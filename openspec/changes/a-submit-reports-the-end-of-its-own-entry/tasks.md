# Tasks

The groups land in order, as one landing, from this change's place on
`change/a-submit-reports-the-end-of-its-own-entry`, cut from
`bolt/sluice-tells-each-submitter-its-own-end`, the base every check
below runs against. Run a suite's test through sluice (`sluice exec
bolt/sluice-tells-each-submitter-its-own-end -- cargo test ...`). A
quick `cargo check`, `cargo clippy` or one unit test may run directly.
Tests use scratch repositories, a bare clone, its git directory as the
folder a command runs in, a worktree of it, a remote and the GitHub
double only, never a real account or the host's own sluice state. Commit
by pathspec (`git add <paths>; git commit -m "<subject>" -- <paths>`),
Conventional Commits scoped to the part of the tree, citing clauses by
number and rules by id. The code's commits are `fix`. A task is done
when its check passes as written.
