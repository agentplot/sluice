# Tasks

Work in this change's place on its branch, cut from
`bolt/a-hosts-switch-fails-no-run`, which is its base. A quick
`cargo clippy` or one test by name of a fast target runs directly; a
test of the `tools` feature runs through
`sluice exec bolt/a-hosts-switch-fails-no-run -- …`, as CLAUDE.md's
Running checks has it. No test reads the host's own
`/run/current-system`: the profile's tests name a link of their own with
`Checks::with_system_link`, the binary's with `SLUICE_SYSTEM_LINK`, and
the fakes with `World::nix_system`. Commit by pathspec, Conventional
Commits, scoped to the part of the tree, citing clauses by number,
record 0097 and rules by id.
