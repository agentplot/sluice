# Tasks

Each group's tests run in the gate's moon tasks, `core:test`,
`cli:test` and `cli:tools` (`crates/*/moon.yml`); while iterating, run
one with `sluice exec main -- cargo test -p sluice --features tools
--test <file> <name>`, and before submitting the gate whole with
`sluice exec main`.
