# Tasks

The groups land in order, as one landing, from this change's place on
`change/pull-requests-are-queued-on-the-forge`, into
`bolt/sluice-runs-one-host-process`. Run suites through sluice against
that base (`sluice exec bolt/sluice-runs-one-host-process -- cargo test
...`); a quick `cargo check` or one unit test may run directly. Tests
use scratch repositories, a bare clone standing for GitHub's git, other
hosts' scratch clones (`OnGitHub::other`) and the GitHub double only,
never a real account or the host's own sluice state. Commit by
pathspec, Conventional Commits scoped to the part of the tree, citing
clauses by number and rules by id. Each task lands the site's and the
plugin's words for what it changes where it names them.

Where `a-hosts-queues-move-in-sluices-own-host-process` has landed on
the bolt, `Command::Run`'s pass is `host_process::pass::pass`, and a
task that names the one means whichever stands.
