- [x] 1.4 Add `Checkout::release_gone` and `GoneRelease` to `crates/sluice-seams/src/lib.rs` (design D1); implement it on `FakeCheckout` (the world counts the stored release's runs and can make it fail), add `Runs::release_gone(name, cwd)` in `crates/sluice/src/runs.rs`, and implement it on `Places` in `crates/sluice/src/profiles/places.rs`: note the started gone release on the place's record, run the last run's stored release once in the place's scratch directory with its stored environment, then free as `free` does whatever it did; a place whose record notes a started gone release is freed with nothing run; verify new tests in `crates/sluice/tests/profiles/places.rs` (`--test places`): a deleted combination's checkout whose stored release writes its working directory and `$PORT` to a marker writes it once, naming the scratch directory and the place's port; a `[tests] toolchain` that writes a marker is not run again; a release that exits 2 is returned as `failed` and git no longer lists the checkout, its block of ports is free and its record gone; a second `release_gone` runs nothing; a place whose runs stored no release returns `ran: false`.
