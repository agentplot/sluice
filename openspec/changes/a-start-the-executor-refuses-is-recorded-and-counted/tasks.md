# Tasks

Each group is one session's work for an implementer who reads this
change (proposal, design, specs) and its own group. The groups land in
order, as one landing. Run suites through sluice (`sluice exec main --
cargo test ...`); a quick `cargo check` or one unit test may run
directly. No test reaches a credential or the host's own sluice state:
set `XDG_STATE_HOME` to the test's scratch directory, and isolate every
git call. Tests of the sandbox run on macOS only, as
`crates/sluice/tests/checks.rs` already gates them. Commit by pathspec
(`git add <paths>; git commit -m "<subject>" -- <paths>`), Conventional
Commits, scoped to the part of the tree, citing clauses by number and
rules by id. Every group ends with its check task passing.
